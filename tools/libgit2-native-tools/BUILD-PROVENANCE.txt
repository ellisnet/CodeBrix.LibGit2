WHY THIS FILE EXISTS
--------------------------------------------------------------------------------
A binary in a package is anonymous. This file is how anyone later can tell which
native library came from which source, which toolchain and which build machine -
without which "rebuild it and see if it matches" is not a question that can even
be asked. Every time a binary is adopted into ../../native_libraries/<rid>/, its
section here is updated from that build's output/<rid>/BUILD-INFO.txt (or
BUILD-INFO.json) and the <file>.provenance.txt beside the binary is written from
the same values.

                    libgit2 ignore LIBGIT2_FILENAME (the file came out as
                    liblibgit2package.so). Removed: on Android CMake does not
                    version shared libraries anyway, so the default already
                    gives one plain libgit2-5853918.so with SONAME
                    libgit2-5853918.so.
